# Neobrutalism Components Svelte
## Not affiliated with [ekmas](https://github.com/ekmas)

## Introduction
This is a port of [ekmas/neobrutalism-components](https://github.com/ekmas/neobrutalism-components) to Svelte

## Documentation
When installing this package include this code in your global css file:
```
@import "tailwindcss";
@import "../node_modules/neobrutalism-components-svelte/dist/style.css";
@source "../node_modules/neobrutalism-components-svelte/dist";
```
